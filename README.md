# Pixel na warstwie

An under-construction landing page for a Polish 3D printing studio. The current repository contains a responsive, single-page Next.js frontend that communicates the redesign status through a custom pixel-inspired visual system.

## Current implementation

- Responsive landing page built with the Next.js App Router
- Custom CSS gradients, grid textures, and pixel composition
- Accessible semantic page structure
- Static production output with no external runtime dependencies
- Polish-language content tailored to the studio brand

## Tech stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4

## Run locally

Requirements: Node.js 20+ and npm.

```bash
git clone https://github.com/WielechJW/pixel-na-warstwie.git
cd pixel-na-warstwie/frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To verify a production build:

```bash
npm run build
```

## Project status

This is currently a focused “under construction” page rather than the complete studio platform. A CMS, catalogue, e-commerce flow, and deployment configuration are not part of the public code at this stage.
